1. Configuração Inicial

Antes de criar fichas, registe a sua base de dados nos separadores laterais:

  • ● 👥 Técnicos: Atribua códigos (ex: 101, LUZ1, JOAO).
  • ● 📍 Locais: Use siglas para os espaços (ex: TNM para Teatro Nacional).
⚡

Atalhos Mágicos (Shortcodes)

A forma mais rápida de preencher escalas no mundo:

1. Escreva o código 101 na célula.
2. Pressione [Espaço] ou [Enter].
3. O sistema converte para NOME DO TÉCNICO.
⏳

2. Gestão de Horários

O sistema organiza o dia por si:

  • ↕️
    Ordenação Automática

    Se mudar uma hora (ex: de 20h para 08h), a linha "salta" sozinha para a posição correta.

  • ↔️
    Fase Flexível

    O campo "Fase" é expansível. Escreva descrições longas; a tabela estica para não cortar texto.
